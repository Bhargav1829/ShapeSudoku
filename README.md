# 🔷 Shape Sudoku

A premium, gamified visual reasoning game inspired by Sudoku, where
traditional numbers are replaced with colorful geometric shapes.

Shape Sudoku is designed to help students improve logical thinking,
pattern recognition, concentration, accuracy, and problem-solving speed
through an interactive gaming experience.

---

## 🎮 Features

- 🎯 Manual level selection
- 🔷 Shape-based Sudoku gameplay
- 📐 Multiple grid sizes
- ⏱️ Real-time timer
- ❤️ 3 lives per game
- 💡 Hint system
- ⭐ Score calculation
- 🎲 Randomized puzzles
- 🏆 Challenge mode
- 📊 Performance-based scoring
- ✨ Premium gaming interface
- 📱 Responsive design

---

## 🧩 Game Levels

| Level | Grid Size | Difficulty |
|------|-----------|------------|
| Level 1 | 3 × 3 | Easy |
| Level 2 | 4 × 4 | Easy |
| Level 3 | 5 × 5 | Medium |
| Level 4 | 6 × 6 | Medium-Hard |
| Level 5 | 7 × 7 | Hard |
| Level 6 | 8 × 8 | Very Hard |
| Challenge | 8 × 8 | Extreme |

The player can manually select any level without completing previous
levels.

---

## 🧠 Shapes

Different levels introduce different shapes:

- 🔵 Circle
- 🔺 Triangle
- 🟦 Square
- 🔷 Diamond
- ⭐ Star
- ⬡ Hexagon
- 🛑 Octagon
- ✚ Plus

Each puzzle requires the player to place the correct shapes while
following the row and column rules.

---

## 🎮 How to Play

1. Open the game.
2. Select any level.
3. Select an empty cell.
4. Choose the shape you want to place.
5. Complete the puzzle.
6. Click **Check**.
7. Avoid mistakes to preserve your lives.
8. Use hints when necessary.
9. Complete the puzzle as quickly as possible for a higher score.

---

## ⭐ Scoring System

The score is based on:

- Grid size
- Solving speed
- Remaining lives
- Mistakes
- Hints used

Larger and more difficult puzzles provide higher base scores.
